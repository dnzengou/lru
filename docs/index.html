Inspiration

Inverting the 2022 Nobel question

Aspect, Clauser & Zeilinger's experiments with entangled photons showed the universe we inhabit is not locally real — which fuelled the modern simulation-hypothesis conversation. LRU flips the question.

"What does it take to build a universe that is locally real — from scratch? And then study it against our locally unreal one."
LRU — a deterministic, causally closed, self-modelling micro-universe. Not a physics simulator; a counterpoint.
What it does

Five sealed primitives

🧠

Neural MVU

GRU recurrent core with 8-head attention. Trains a self-model and tracks Φ, entropy, and closure score each tick.

🔗

Causal wall

Every step hashes into a SHA-256 chain. The wall is verifiable, offline, and tamper-evident.

🗳

DAO governance

Proposals, votes, treasury. Parameter mutations only pass with quorum and threshold — containment never waived.

🔥

Phoenix Protocol

When closure collapses below a threshold the universe snapshots, mutates, and rebirths itself.

🌱

Child spawning

Spawn mutant children, register them, score fitness, select survivors. Evolution without a genome file.

📡

Cross-track comms

Universes broadcast state deltas; a live dashboard visualises Φ, closure, and Phoenix events in real time.

Architecture

One lifecycle, three engines

POSIX shell for the offline path, Python for the enhanced trainer, Go for the HTTP governance surface. All three share JSON state under LRU_BASE_DIR.

Quickstart

Clone, train, spawn.

POSIX box with bash, awk, bc. Add Python 3 or Go only if you want the enhanced engines.

# Full lifecycle: train → run → spawn → DAO evolve
git clone https://github.com/dnzengou/lru.git && cd lru
make all

# Or more granular
make train TRAIN_STEPS=200
make run   RUN_STEPS=100
make spawn
make evolve
make status
make phoenix
# Direct engine
bash scripts/run_universe.sh --help
bash scripts/run_universe.sh --train 200
bash scripts/run_universe.sh --train-fast 500
bash scripts/run_universe.sh --run 100
bash scripts/run_universe.sh --evolve
bash scripts/run_universe.sh --benchmark
# Containerised full stack
make docker-build
make docker-run
# Dashboard at http://localhost:8080/
# Go DAO HTTP engine
make go-build
make go-run

# Endpoints
curl localhost:8080/status
curl localhost:8080/train -d 'steps=100'
curl localhost:8080/propose -d '...'
Research themes

The broad sandbox

LRU is where speculative and biomimetic frames live — kept out of hardened productised tools so their lexicon stays plain.

🌐 SEIR dynamics

Modelling policy-drift spread across a universe's children.

🛰 Kessler syndrome

Cascade failure of orbital constraints as a metaphor for runaway mutation.

👑 Red Queen

Co-evolving self-model vs. environment — running to stay in place.

🌲 Trophic cascade

Top-down effects of a Phoenix rebirth on the child registry.

🛡 DARE posture

Deterrence · Assurance · Reassurance · Engagement around the DAO.

🧫 Biomimicry

Quorum sensing, autoinducers, sporulation thresholds.

🏯 Costate / citadel

Dual-process guardrails around the self-model.

🌿 Garden game

The playable "tend a locally real universe" layer.

⚛ Stoic / quantum essays

Why a locally real universe is a worthwhile foil to our locally unreal one.
